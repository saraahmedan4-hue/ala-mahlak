# على مهلك · Ala Mahlak

رحلة بدون مفاجآت، وبدون استعجال. نموذج أولي لهاكاثون AgentX (مسار المدن الذكية وجودة الحياة).

موقع ثابت واحد:
- **لوحة الهيئة** (تفتح أول شي): البلاغات، ودرجة موثوقية الأماكن من 0 إلى 10، والوكلاء الثلاثة.
- **زر «جرّبي كمستخدمة»**: يفتح التطبيق داخل إطار جوال، وفيه الرحلة الذهبية (5 خطوات). البلاغ اللي ترسله المستخدمة يطلع في اللوحة مباشرة.

## التشغيل
ما يحتاج تثبيت ولا بناء. افتح `index.html` من أي خادم ثابت، مثلاً:
```
python3 -m http.server
```

## النشر
- **Netlify**: اسحب المجلد كامل وأفلته في https://app.netlify.com/drop، أو اربط المستودع (Import from GitHub) بدون أمر بناء ومجلد النشر `/`.
- **GitHub Pages**: Settings ← Pages ← Deploy from a branch.

## الملفات
- `index.html`: الصفحة
- `css/styles.css`: الهوية (دليل الهوية v4)
- `js/data.js`: البيانات التجريبية (seed)
- `js/i18n.js`: النصوص بالعربي والإنجليزي
- `js/app.js`: الحالة، ودرجة الموثوقية، والوكلاء، والرحلة
- `vendor/`: MapLibre GL 4.7.1 (BSD-3)
- `assets/logo.svg`: الشعار

البيانات تجريبية للعرض. المصادر في [DATA_SOURCES.md](DATA_SOURCES.md).
