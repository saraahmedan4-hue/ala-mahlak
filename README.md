# على مهلك · Ala Mahlak

رحلة بدون مفاجآت، وبدون استعجال. نموذج أولي لهاكاثون AgentX (مسار المدن الذكية وجودة الحياة).

موقع ثابت واحد يبدأ بشاشة اختيار:
- **أنا مستخدم**: واجهة ويب كاملة فيها خريطة الرياض، والأماكن المهيأة (مصعد، منحدر، مدخل مخصص، دورة مياه، مواقف) ودرجة الموثوقية، والرحلة الذهبية (5 خطوات).
- **أنا من الهيئة**: الأرقام، وملخص اليوم، والخريطة بدرجات 0–10، والبلاغات مع موافقة/تحويل. البلاغ اللي يرسله المستخدم يطلع هنا مباشرة.

علامة ✦ تعني «شغل الذكاء الاصطناعي» (مقارنة المسارات، التحويل التلقائي، كتابة البلاغ، دمج المكرر، ملخص اليوم).

> كل البيانات تجريبية للعرض (الإتاحة، البلاغات، المسارات، المدد). الأماكن وإحداثياتها والخريطة من OpenStreetMap.

## التشغيل
ما يحتاج تثبيت ولا بناء. افتح `index.html` من أي خادم ثابت، مثلاً:
```
python3 -m http.server
```

## النشر
- **Netlify**: اسحب المجلد كامل وأفلته في https://app.netlify.com/drop، أو اربط المستودع (Import from GitHub) بدون أمر بناء ومجلد النشر `/`.
- **GitHub Pages**: Settings ← Pages ← Deploy from a branch.

## الملفات
- `index.html`: الصفحة
- `css/styles.css`: الهوية (دليل الهوية v4)
- `js/data.js`: البيانات التجريبية (seed)
- `js/i18n.js`: النصوص بالعربي والإنجليزي
- `js/app.js`: الحالة، ودرجة الموثوقية، والواجهتين، والرحلة
- `js/map.js` + `js/map-data.js`: خريطة SVG مضمّنة (تشتغل بدون نت)
- `tools/build-map.mjs`: يعيد بناء `map-data.js` من بلاطات OpenFreeMap
- `brand/`: الشعار

البيانات تجريبية للعرض. المصادر في [DATA_SOURCES.md](DATA_SOURCES.md).
